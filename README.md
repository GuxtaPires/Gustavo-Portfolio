## 📌 Sobre o projeto

Este repositório contém o código-fonte do meu **Portfólio Pessoal**, desenvolvido para centralizar minha trajetória profissional e acadêmica, habilidades técnicas e principais projetos nas áreas de **Data & Analytics, Ciência de Dados e Desenvolvimento de Software**.

A aplicação web foi construída com foco em performance, responsividade e experiência do usuário (*UI/UX*), reunindo dashboards interativos, pipelines de dados e aplicações desenvolvidas ao longo da minha jornada.

🌐 **Acesse online:** [Visualizar Portfólio](https://guxtapires.github.io/) *(ajuste caso o nome do repositório seja diferente)*

---

## 🎯 Objetivos

- Apresentar de forma clara e interativa meu perfil profissional, formação e experiências.
- Reunir em um único ambiente projetos de **Data Analytics, Python, SQL, Power BI** e desenvolvimento de software.
- Facilitar o acesso rápido aos repositórios no GitHub, aplicações publicadas e canais diretos de contato.
- Aplicar boas práticas de design responsivo, animações suaves e organização de código front-end.

---

## 🛠️ Tecnologias e ferramentas

| Tecnologia | Aplicação |
| :--- | :--- |
| **HTML5** | Estruturação semântica das seções da página (*Hero, Sobre, Skills, Jornada, Projetos e Contato*). |
| **Tailwind CSS** | Estilização utilitária, grid responsivo, gradientes e adaptação para dispositivos móveis. |
| **CSS3 (`style.css`)** | Efeitos de *Glassmorphism*, animações de fundo (*blobs*), linha do tempo e barra de rolagem customizada. |
| **JavaScript (`script.js`)** | Efeito de digitação dinâmica, filtro interativo de projetos, cópia rápida de e-mail e animações de *Scroll Reveal*. |
| **Font Awesome** | Ícones vetoriais para identificação visual de tecnologias, contatos e navegação. |

## 📊 Estrutura da solução

O site está organizado em seis seções principais de navegação contínua:

### 1. Apresentação (`#hero`)
- Introdução profissional com efeito de digitação dinâmico alternando entre áreas de atuação (*Data & Analytics, Ciência de Dados & IA, Python, SQL & Power BI*).
- Atalhos diretos para os projetos e perfil do GitHub.

### 2. Sobre Mim (`#about`)
- Resumo da transição entre Logística e Tecnologia, formação em **Análise e Desenvolvimento de Sistemas (FATEC Guarulhos)** e atuação atual em **Data & Analytics no Santander**.

### 3. Habilidades (`#skills`)
- Cartões interativos com barras de progresso animadas destacando proficiência em **Python, SQL, Power BI e Ciência de Dados**, além de competências complementares (*Git, Java, C#, Firebase, AWS*).

### 4. Minha Jornada (`#work`)
- Linha do tempo vertical detalhando experiências profissionais e acadêmicas (**Santander Brasil, FATEC Guarulhos, LATAM Airlines e ETEC Guarulhos**).

### 5. Meus Projetos (`#projects`)
- Vitrine filtrável por categoria (`Todos`, `Dados & BI`, `Mobile & Dev`) apresentando os projetos **Brasileirão Analytics**, **Dashboard de Salários — Dados**, **Carson** e **Cálculo e Classificação Salarial**.

### 6. Contato (`#contact`)
- Formulário de envio rápido, botão de **cópia de e-mail com um clique** e links diretos para LinkedIn e GitHub.

### Estrutura de Arquivos

```text
portfolio/
├── index.html      # Estrutura principal da página
├── style.css       # Estilos customizados, glassmorphism e animações
├── script.js       # Lógica de filtros, typing effect, clipboard e scroll reveal
└── README.md       # Documentação do repositório
```

## 🔄 Processo de desenvolvimento e execução

### Execução Local

1. **Clonar o repositório:**
   ```bash
   git clone [https://github.com/GuxtaPires/seu-repositorio-portfolio.git](https://github.com/GuxtaPires/seu-repositorio-portfolio.git)
   ```
2. **Acessar o diretório do projeto:**
   ```bash
   cd seu-repositorio-portfolio
   ```
3. **Abrir no navegador:**
   - Basta abrir o arquivo `index.html` diretamente no navegador ou utilizar a extensão **Live Server** no VS Code.
